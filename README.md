# 🚗 Ford Car Price Prediction

This project analyzes and predicts used **Ford car prices** using data from Kaggle.  
It explores how features like **year, mileage, engine size, fuel type, and tax** influence car prices.

## 📊 Dataset
- **Source:** [Kaggle – Ford Car Price Prediction](https://www.kaggle.com/datasets/adhurimquku/ford-car-price-prediction)
- **Features:**
  - `model`
  - `year`
  - `price`
  - `transmission`
  - `mileage`
  - `fuelType`
  - `tax`
  - `mpg`
  - `engineSize`

## 🧠 Analysis Highlights
- **Year** and **Mileage** are the strongest predictors of price.  
- **Engine size** and **Tax** show moderate influence.  
- **MPG** has a weaker correlation with price.  
- Data visualization and regression models were used to uncover these relationships.
